# research/ —— 研究期留档

这里放的是**做这个脚本时用过的抓取/比对工具和数据快照**，不是构建产物，运行时用不到。

## 背景

站点的界面文案藏在它的前端构建产物里，我做汉化时的流程是：抓下页面与消息文件 → 解析出 `live2d` 这一组文案 → 和上游 moenotes 的 i18n 英 / 中文对照 → 生成 `*.tsv` 词表 → 再把线上实测跑出来的「没翻到」清单整理成 `live-unmatched.txt`。

## 文件

| 文件 | 是什么 |
| --- | --- |
| `check_page_keys.js` | 解析抓到的 Astro 消息文件，把缩进的嵌套块摊平成 `"key": "value"` 平表（支持单行与多行两种写法）。当时用来核对线上页面到底有哪些 key。 |
| `diff_live2d.js` | 抽出消息文件里的 `live2d: { … }` 块，把线上 / 上游、英文 / 中文几份快照互相 diff，找出「线上有、词表没有」的漏翻文案。 |
| `fmt_en.json` | 线上抓到的 `filter` / `loader` / `seo` 等格式化消息（英文）。 |
| `fmt_zhMain.json` | 上游 `main` 分支同一组消息的中文版本。 |
| `fmt_zhOld.json` | 更早分支的中文版本，用来对比译文变动。 |
| `live2d_en_main.json` | 上游 `main` 分支的 `live2d` 文案组（英文）。词表的主要来源。 |
| `live2d_zh_main.json` | 上游 `main` 分支的 `live2d` 文案组（简体中文）。 |
| `live2d_zh_old.json` | 更早分支的 `live2d` 中文文案，用于确认译文是否变过。 |

## 注意

那两个 `.js` 是当时的**一次性脚本**，里面硬编码了抓取时的临时目录（DSH 的 `Temp/dsh-spill-*/session-*/`），那批中间文件早就没了，所以**现在直接跑会报找不到文件**。留着是为了记录「这些快照是怎么来的」；快照本身（`.json`）才是可复用的数据。

要重新抓一遍的话，思路是：从站点前端资源里找到消息文件 → 用这两个脚本的解析逻辑摊平 → 与 `main` 分支的 `src/i18n` 对照。
